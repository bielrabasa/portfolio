C++ · OpenGL · GLSL

Game Engine

I co-developed this C++ and OpenGL engine with Roger Salas for our 2022–23 university project. My work covered the scene system, rendering and asset import.

  • Scene architecture. Built the game object hierarchy and component system, including parent-relative transforms and components for cameras, meshes, textures and shaders.
  • Rendering and asset import. Worked on the OpenGL render pipeline and implemented drag-and-drop import for FBX and DAE models, textures and GLSL files. Imported models were added to the scene as game objects with mesh and texture components.
  • Shader pipeline. Implemented default shaders and inspector controls for shader uniforms. The engine recompiles GLSL on save and updates objects using that shader. I also built the demo scene and wrote its water shader.
